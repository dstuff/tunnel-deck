The complete modifications are provided as script/xray_compat.patch in the
TunnelDeck source distribution. Rebuild with script/build_xray_compat.sh using
Go 1.26.0. These modifications are made available under MPL 2.0.
The application bundle also includes the patch and build script in Runtime/source.

The opt-in REALITY fingerprint "tunneldeck_safari15_5" starts with the public
uTLS Safari 16 preset, removes ALPN, and keeps one RSA-PSS-SHA384 signature
entry. This implements the compatibility profile using public uTLS presets
and TLS configuration values. Other fingerprints retain their
upstream behavior. Xray's numeric version and REALITY authentication version
are unchanged. The runtime identifies this build as TunnelDeck.2.

The profile approximates the observed default Safari 15.5 ClientHello. It does
not claim byte-for-byte equivalence to native BoringSSL serialization or TCP
behavior, and it does not change Xray's certificate verification or REALITY
authentication logic.
